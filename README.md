# 287 Tester — releases

Installers of the Corsano 287-2B test tool and the test firmware it flashes.

| Tag | Asset |
|---|---|
| `gui-v<version>` | `287Tester-Setup-<version>.exe` — Windows installer of the tester |
| `fw-v<version>` | `FW287_2B_Multicolor_big_<x>_<y>.zip` — full DFU package (softdevice + bootloader + application) |

The tester checks this page at start-up and its **Get latest** button downloads the newest
test firmware.
